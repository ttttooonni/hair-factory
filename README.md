# HAIR FACTORY · PWA

PWA estática para Hair Factory Peluquería, El Tablero. Diseñada para GitHub Pages, móvil y escritorio.

## Datos configurados
- Dirección: Calle Brasil, 2 · El Tablero · San Bartolomé de Tirajana
- Teléfono: 674 96 09 50
- WhatsApp: configurado
- Google Maps: búsqueda por dirección
- Reseñas: acceso a Google Maps para localizar/valorar el negocio
- Reservas: WhatsApp hasta disponer de un sistema de agenda específico

## Identidad
El logotipo original proporcionado para el proyecto se mantiene como logo principal de la PWA, favicon e identidad visual. La interfaz usa una estética editorial/barbería en negro, blanco, gris cálido y detalles inspirados en el carácter del sello.

## Auditoría técnica
- Sin dependencias externas ni API keys.
- HTML con `lang`, viewport, metadatos SEO y datos estructurados.
- JavaScript sin dependencias; sintaxis comprobable con Node.
- Rutas relativas compatibles con GitHub Pages bajo subruta.
- Manifest válido e iconos PWA incluidos.
- Service Worker con caché offline y limpieza de versiones anteriores.
- Menú y modales implementados con `<dialog>`.
- Enlaces de teléfono, WhatsApp y Maps funcionales.
- Sin precios inventados ni horarios inventados.
- Sin almacenamiento de datos personales del cliente.

## Publicación
Subir el contenido de esta carpeta a un repositorio y activar GitHub Pages desde `main` + root. Después comprobar la URL HTTPS final y ejecutar Lighthouse.
